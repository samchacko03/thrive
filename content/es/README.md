# Español

Copy every file from `content/en/` into this folder and translate the text values only.
Keep every `key`, `id`, and `a` value exactly the same; the app matches on those.
When all seven files exist here, change `<html lang="en">` to `lang="es"` in a copy of
`index.html` named `es.html` (or add a language toggle), and the app will load Spanish.
